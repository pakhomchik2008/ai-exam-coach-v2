# Phase 5 — GMAT Focus

Same quality bar as GRE: official structure, real scale, paper language,
verified curriculum. Focus Edition is the current GMAT: Quant 21/45,
Verbal 23/45, Data Insights 20/45. Total 205–805 (tens, ends in 5).
Sections 60–90, equally weighted. No AWA. No Sentence Correction. No
Quant geometry. Data Sufficiency is DI, not Quant.
